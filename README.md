# Story Input Combiner

A simple Python program that combines multiple lines of user input into a single story-like output. The program checks whether each input begins with a question word such as **"why"** or **"what"** and automatically adds a question mark (`?`) to those inputs. Other inputs receive a period (`.`). The processed lines are then combined into one continuous string. This project demonstrates the use of functions, lists, loops, string methods, and conditional statements in Python.

## Features

* Allows users to enter multiple lines of text.
* Automatically detects inputs beginning with `"why"` or `"what"`.
* Adds `?` to questions and `.` to other sentences.
* Combines all processed inputs into a single output.
* Demonstrates functions, lists, loops, string manipulation, and conditionals.

## How to Run

1. Make sure Python 3 is installed.
2. Run the script:

   ```bash
   python story_generator.py
   ```
3. Enter the number of lines you want to add.
4. Enter each line when prompted.

## Example

```text
Welcome to combining your input using the story generator!
How many lines do you want to add? 3

input : What happened
input : I went to the park
input : Why did you leave

What happened? I went to the park. Why did you leave?
```
